# INFO 450: Advanced Software Development

Welcome to the repository for **INFO 450 (Advanced Software Development)** at **Virginia Commonwealth University (VCU)**. This repository houses coursework, project assignments, code samples, and practical implementations developed throughout the semester.

---

## 📖 Course Overview

**INFO 450** focuses on advanced software engineering principles, modern full-stack development, architectural patterns, and practical application building. The course bridges fundamental programming logic with real-world, enterprise-level development practices.

### Key Concepts Covered
* **Software Architecture & Design Patterns:** MVC, RESTful API design, modular architecture.
* **Full-Stack Development:** Front-end integration, back-end logic, and database management.
* **Database Systems:** Relational database design, SQL querying, and ORM usage.
* **Version Control & DevOps:** Git/GitHub workflows, branch management, and CI/CD basics.
* **Agile Methodologies:** Scrum workflows, project tracking, and iterative development.
